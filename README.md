A robot vacuum’s deadpan one-line alibi for missing a spot: the cat sat on it for forty minutes, and I do not vacuum cats. That is policy, not cowardice. A small deterministic Python program writes the line to /output/entry.txt.

## Run it

```sh
python3 main.py  # writes the line to /output/entry.txt
```
